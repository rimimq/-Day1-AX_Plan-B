# Plan-B 1차 MVP 요약

## 만들려는 것

CR에 이미 들어있는 차시, 파트, 챕터, 클립명, 러닝타임 정보를 바탕으로 운영계획서에 들어갈 과정별 서술 초안을 자동 생성한다.

BO는 AI 초안을 그대로 제출하는 것이 아니라, Google Sheets에서 검토/수정/승인한다.

## 왜 필요한가

운영계획서 작성 시 CR과 훈련시간계획서에 이미 있는 내용을 운영계획서 문체로 다시 풀어 쓰는 반복 업무가 발생한다.

1차 MVP는 최종 문서 자동 제출이 아니라, 반복 작성 시간을 줄이는 검토용 초안 생성을 목표로 한다.

## 1차 MVP 흐름

1. CR 데이터 입력
2. AI가 과정 개요, 차시별 학습내용, 학습소요시간 산정사유 초안 생성
3. 실습/프로젝트로 보이는 차시는 별도 후보로 표시
4. BO가 Sheets에서 수정 및 승인
5. 승인된 데이터는 후속 Docs/PDF 자동 생성의 입력으로 사용

## 자동 생성 대상

| 항목 | 설명 |
| --- | --- |
| 과정 개요 | 과정 목적, 학습 흐름, 기대 성과 |
| 차시별 학습내용 | 차시/파트/챕터/클립 기반 서술 초안 |
| 학습목표 | 차시별 학습자가 달성할 목표 |
| 학습소요시간 산정사유 | 러닝타임과 복습/실습/정리 시간을 고려한 사유 |
| 실습/프로젝트 후보 | 키워드 기반 후보 탐지 및 BO 검토 표시 |

## BO에게 확인하고 싶은 것

| 질문 | 확인 목적 |
| --- | --- |
| 이 초안이 있으면 작성 시간이 줄어들 것 같은가? | 업무효율 검증 |
| 가장 쓸 만한 자동 생성 필드는 무엇인가? | MVP 우선순위 확정 |
| 가장 많이 수정해야 할 필드는 무엇인가? | 프롬프트 개선 |
| 산정사유 문체가 제출용 문체와 맞는가? | 문체 기준 확정 |
| 실습/프로젝트 후보 표시가 도움이 되는가? | 기능 유지 여부 결정 |
| Sheets에서 검토/수정/승인하는 방식이 편한가? | 사용 방식 검증 |

## 1차 MVP에서 하지 않는 것

- 운영계획서 최종 Docs/PDF 자동 생성
- HRD-Net 직접 제출
- 교강사 DB 자동 추천
- 심사 적합성 자동 판정

## 성공 기준

- BO의 반복 작성 시간이 줄어든다.
- AI 초안이 BO 수정 후 사용할 수 있는 수준이다.
- 승인된 데이터가 후속 문서 자동화에 재사용 가능한 구조로 저장된다.
